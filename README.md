# BARQLO

BARQLO is an Arabic-first AI business platform for customer conversations and sales operations across 35 commercial sectors.

The platform combines preparation and verification before a customer-facing reply, supports tenant-specific business data and dialect preferences, and provides owner and team workspaces.

**New version in progress — 12 November 2026.** The production implementation, workflows, database migrations, configuration, customer data, and deployment files are maintained privately. This public repository is a product overview only.
